# طرح فنی

- تنظیمات در JSON محلی یا جدول singleton PostgreSQL ذخیره می‌شود. اعتبارسنجی با Zod.
- تکه‌بندی با RecursiveCharacterTextSplitter، MarkdownTextSplitter و TokenTextSplitter انجام می‌شود. روش پاراگرافی، اسناد پاراگراف را پیش از splitter بازگشتی جدا می‌کند.
- بازسازی نسخه‌دار: قطعه‌های جدید شاخص‌گذاری، منبع فعال به نسخهٔ جدید منتقل، سپس قطعه‌های قبلی پاک می‌شوند. خطا به نسخهٔ قبلی بازمی‌گردد.
- بازیابی داخلی score را با آستانهٔ تنظیم‌شده می‌سنجد. جست‌وجوی بیرونی از Tavily در endpoint سازگار AvalAI استفاده می‌کند. پاسخ فقط نقل‌قول‌های تأییدشدهٔ شاهدهای داخلی یا وب را می‌پذیرد.
- API تنظیمات فقط برای مدیر؛ API نام منابع برای چت عمومی. API پیوست چت بسته می‌شود.
