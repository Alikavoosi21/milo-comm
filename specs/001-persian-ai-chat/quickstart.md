# راهنمای اعتبارسنجی سرتاسری

## پیش‌نیازها

- Node.js 22 LTS و یک PostgreSQL محلی یا سرویس توسعه
- فضای شیء خصوصی یا آداپتر local-only برای توسعه
- متغیرهای محیطی `AI_BASE_URL`، `AI_API_KEY` و `AI_MODEL`

## سناریوهای تأیید

1. سرویس‌های محلی را راه‌اندازی و schema پایگاه‌داده را اعمال کنید.
2. برنامه را اجرا کنید و در مرورگر فارسی، گفتگوی جدید بسازید.
3. دو پیام مرتبط بفرستید؛ پاسخ دوم باید به زمینهٔ پیام اول توجه کند و مراحل واقعی تولید در UI دیده شوند.
4. یک TXT یا PDF کمتر از 10MB پیوست کنید؛ نوع‌های مجاز را ببینید و دربارهٔ فایل پرسش کنید.
5. یک ZIP، فایل اجرایی یا فایل بزرگ‌تر از 10MB انتخاب کنید؛ علت رد، نوع‌های مجاز و متن حفظ‌شدهٔ پیام را ببینید.
6. دو گفتگو بسازید، اولی را به دومی ارجاع دهید و تأیید کنید گفتگوی انتخاب‌نشده وارد پاسخ نمی‌شود.
7. یک پیام را ویرایش و ادامهٔ تازه بسازید؛ شاخهٔ قدیمی باید جدا و پاسخ تازه فقط بر مسیر جدید تکیه کند.
8. تم را تغییر دهید، صفحه را باز کنید و جریان اصلی را با صفحه‌کلید در دسکتاپ و موبایل کامل کنید.

قرارداد در [contracts/chat-api.yaml](./contracts/chat-api.yaml) و مدل داده در
[data-model.md](./data-model.md) است.


## نتیجه اجرای ۲۰۲۶-۰۹-۱۸

- `npm run typecheck`: موفق
- `npm run lint`: موفق
- `npm test`: موفق — ۱۶ فایل و ۲۸ تست
- `npm run test:e2e`: موفق — ۶ سناریوی Chromium
- `npm run build`: موفق — build تولیدی Next.js

سناریوهای چت فارسی، نمایش مرحله تولید، رد فایل نامجاز با حفظ متن، منشن گفتگوی متعلق به کاربر، ویرایش پیام و ایجاد شاخه، ماندگاری تم و کنترل‌های دسترس‌پذیر خودکار تأیید شدند. اجرای محلی به‌طور پیش‌فرض از مدل mock و ذخیره‌سازی خصوصی local-only استفاده می‌کند؛ برای ارائه‌دهنده واقعی باید متغیرهای `AI_*` تنظیم شوند.
